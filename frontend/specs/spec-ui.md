# Todo list application :

- You have to build the complete ui of this website from the fontend perspective only (No backend or any API integration yet.)
- This is almost an empty next js repository and you have to start working on it from scratch .


## Pages & responsibility :

- The  website is gonna have 4 pages i.e :
1 - home page ("/") - here you have to design the ui only i.e add 5-6 sections like hero, cta, testimonials etc .
2 - about page ("/about") - about page describing the app
3 - contact page ("/contact") - build a basic form here to reach out.
4 - todo page ("/todos) - you can redirect to this page from a button present in hero section .
5 - /dashboard - you can enhance this (i have already added content)
6 - /login - you have to enhance this as well (i have already added content)


## Pages you need to add content and design css :

- you must add content from yourself explicitly to make the site look more good, use images from unsplash and all, add images path in next.config.ts when needed .
- use app/layout.tsx for adding navbar and footer so they can be used across different pages.
- use proper html semantics and make the code clean .
- so for homepage, add sections such as :  hero, about-us, testimonials, cta, features (and for layout show footer and navbar)


## styling instrcutions :

- make a light and green theme based application with buttons and cards showing things good, just make animation provided by tailwind natively, dont rely on third party packages . 
- make sure the content of the width present in the website be max-w-7xl.
- suppose if there is a section (eg: hero), make it w-full but its the entire container has to be w-full, but the content must be within 7xl so it will give more modern vibe and structured flow from navbar to footer .
